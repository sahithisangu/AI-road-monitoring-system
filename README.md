
# AI-Based Road Monitoring System

An AI-powered road monitoring solution designed to detect potholes and support road condition assessment using computer vision.

**Smart India Hackathon 2026** | Team selected for the National-level stage

## About the Project

Road damage, especially potholes, can create safety risks for commuters and affect transportation infrastructure.

This project explores the use of Artificial Intelligence and Computer Vision to identify potholes from road images and video footage, helping make road monitoring more efficient.

## 🎯 Project Objectives

- Detect potholes using AI-based object detection.
- Analyse road images and video footage.
- Reduce duplicate pothole detections across video frames.
- Visualise detected road issues through an interactive map.

##  Technology Stack

| Category | Technologies |

| Programming | Python |
| Object Detection | YOLO |
| Computer Vision | OpenCV |
| Backend | FastAPI |
| Frontend | HTML, CSS, JavaScript |
| Mapping | Leaflet.js, OpenStreetMap |

##  Key Features

- Pothole detection using computer vision.
- Image and video-based road analysis.
- Object tracking to minimise duplicate detections.
- Map-based visualisation of road issues.
- Location-based road condition monitoring.
